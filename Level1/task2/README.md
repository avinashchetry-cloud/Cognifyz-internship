# Cognifyz Data Science Internship - Level 1, Task 2

Welcome to my repository for **Level 1 - Task 2: Descriptive Analysis**, completed during my internship with **Cognifyz Technologies**.

## 📌 Task Objective
The primary objective of this task was to perform exploratory data analysis (EDA) to understand the underlying structure of the dataset, calculate core statistical values, and identify key operational trends.

## 🛠️ Key Operations Performed
* **Statistical Calculations:** Evaluated essential statistical measures (mean, median, standard deviation) for numerical features.
* **Categorical Distribution Analysis:** Analyzed categorical variables including "Country Code," "City," and "Cuisines."
* **Top Insights Generation:** Filtered and highlighted top-performing cities and popular cuisines based on restaurant density.

## 🚀 Tools & Libraries Used
* **Python**
* **Pandas / NumPy**
* **Matplotlib / Seaborn** (for data visualization)
