# Data Exploration and Preprocessing Level 1, Task 1

## Project Overview

This project focuses on exploring and preprocessing a dataset to understand its structure, identify data quality issues, and prepare it for further analysis.

## Objectives

### 1. Dataset Exploration
- Identified the total number of rows and columns.
- Examined the dataset structure.
- Reviewed column names and data types.

### 2. Missing Value Analysis
- Checked missing values in each column.
- Identified columns containing null values.
- Handled missing values using appropriate techniques.

### 3. Data Cleaning
- Identified redundant and unnecessary columns.
- Removed columns that did not contribute meaningful information.
- Improved dataset consistency.

### 4. Data Type Conversion
- Examined data types of individual columns.
- Converted columns to appropriate data types wherever required.

### 5. Target Variable Analysis
- Analyzed the distribution of the `Aggregate rating` variable.
- Examined the frequency of different rating categories.
- Used visualizations to understand the distribution.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Learnings

- Understanding dataset structure and quality.
- Identifying and handling missing values.
- Recognizing redundant features.
- Performing data type conversions.
- Exploring categorical and numerical variables.

## Conclusion

This preprocessing phase helped establish a cleaner and more structured dataset, making it suitable for further exploratory data analysis and deeper insights.
